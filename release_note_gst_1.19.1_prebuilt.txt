1) Overview

The release includes four parts: gstreamer, nnstreamer plugin (modified), Ambarella gstreamer plugin, gstreamer daemon (modified).

gstreamer is an open source project, its focus is multimedia processing, its website is https://gstreamer.freedesktop.org/.
gstreamer is an open architecture, it provides a core framework named gstreamer-core, and also along with plenty of elements
 for multimedia processing, like gstreamer-plugin-base, gstreamer-plugin-good, gstreamer-plugin-bad and gstreamer-plugin-ugly.
 Writing plugin/element is an easy and typical way to extend gstreamer capability. Ambarella Flexible Linux SDK include prebuild
 version of gstreamer 1.19.1, its location in SDK is ambarella/prebuild/oss/armv8-a/gstreamer-1*, Ambarella does not modify
 gstreamer-core, gstreamer-plugin-base, gstreamer-plugin-good, gstreamer-plugin-bad and gstreamer-plugin-ugly code, just provide
 as is.

nnstreamer is an open source project, its focus is machine learning in gstreamer, its website is https://nnstreamer.ai/.
nnstreamer is gstreamer plugin, which includes a group of element for machine learning processing, especially for neural network
 inference. Ambarella's modification for nnstreamer is adding Ambarella neural network accelerator support. In Ambarella Flexible
 Linux SDK, the modified nnstreamer is based on nnstreamer version lts-2.0.1. Its location in SDK is ambarella/packages/nnstreamer.

Ambarella gstreamer plugin inncludes elements for multimedia and machine learning related processing on Ambarella platform.
 Current version is 1.0. Its location in SDK is ambarella/packages/amba_gst_plugins.

gstreamer daemon, also called gstd, is a gstreamer framework for controlling audio and video streaming using an interProcess communication
 protocol. Its website is https://developer.ridgerun.com/wiki/index.php?title=GStreamer_Daemon.
 In Ambarella Flexible Linux SDK, the modification is removing dependancy of library readline. The modification is based on gstreamer deamon
 0.14.0, its location in SDK is ambarella/packages/gstd-0.14.0.

Element list in Ambarella plugin:
  amba_camsrc: Amba Camera Source, output YUV frames
  amba_heicfilesink: Ambarella HEIC File Sink
  amba_hwvdec: amba hw video decoder
  amba_hwvdecsrc: Amba HW decode Source, output YUV frames
  amba_venc_overlay: Amba Venc Overlay
  amba_venccap: Amba Video Encoder, capture
  amba_vencdemux: Amba Video Encoder, demux
  amba_vsink: Amba Video Sink
  malsasrc: Audio source (ALSA)
  mlinference: Amba Machine Learning Inference

Element list in nnstreamer plugin (based on lts-2.0.1)
  tensor_aggregator: TensorAggregator
  tensor_converter: TensorConverter
  tensor_crop: TensorCrop
  tensor_decoder: TensorDecoder
  tensor_demux: TensorDemux
  tensor_filter: TensorFilter
  tensor_if: TensorIf
  tensor_merge: TensorMerge
  tensor_mux: TensorMux
  tensor_query_client: TensorQueryClient
  tensor_query_serversink: TensorQueryServerSink
  tensor_query_serversrc: TensorQueryServerSrc
  tensor_rate: TensorRate
  tensor_reposink: TensorRepoSink
  tensor_reposrc: TensorRepoSrc
  tensor_sink: TensorSink
  tensor_sparse_dec: TensorSparseDec
  tensor_sparse_enc: TensorSparseEnc
  tensor_split: TensorSplit
  tensor_src_iio: TensorSrcIIO
  tensor_transform: TensorTransform


2) Compilation:
 2.1) copy and extract the package:
    cp ambarella_gst_v1.0.0.tar.bz2 $(SDK)/ambarella/
    cd $(SDK)/ambarella/
    tar jxvf ambarella_gst_v1.0.0.tar.bz2
 2.2) cd $(SDK)/ambarella/boards/cv22_walnut
 2.3) source ../../build/env/aarch64-linaro-gcc.env
 2.4) make sync_build_mkcfg
 2.5) make cv22_ipcam_config
 2.6) make defconfig_public_linux
 2.7) select ambarella gstreamer plugin, nnstreamer and gstreamer daemon in menuconfig
    make menuconfig ->
      [*] Ambarella Package Configuration --->
        [*]   Build Ambarella GStreamer Plugin
        [*]   Build Ambarella Modified NNStreamer (GStreamer Plugin)
		[*]   Build GStreamer Daemon
 2.8) make gstd && make gst-client
 2.9) make -j16
Above will compile whole SDK, with ambarella gst plugin, if user only want to compile the plugin, can type
 2.10) make libgstamba.so
 2.11) make libgstnnstreamer.so

The compiled Ambarella plugin can be found at
 "$(SDK)/ambarella/out/cv22_walnut/packages/amba_gst_plugins/src/libgstamba.so"
 or
 "$(SDK)/ambarella/out/cv22_walnut/fakeroot/usr/lib/gstreamer-1.0/libgstamba.so"

The compiled nnstreamer plugin can be found at
 "$(SDK)/ambarella/out/cv22_walnut/packages/nnstreamer/libgstnnstreamer.so"
 or
 "$(SDK)/ambarella/out/cv22_walnut/fakeroot/usr/lib/gstreamer-1.0/libgstnnstreamer.so"

The compiled gstreamer daemon (gstd and gst-client) can be found at
 "$(SDK)/ambarella/out/cv22_walnut/packages/gstd-0.14.0/gstd/gstd"
 "$(SDK)/ambarella/out/cv22_walnut/packages/gstd-0.14.0/gst_client/gst-client"
 or
 "$(SDK)/ambarella/out/cv22_walnut/fakeroot/usr/local/bin/gstd"
 "$(SDK)/ambarella/out/cv22_walnut/fakeroot/usr/local/bin/gst-client"

The plugins at board's location: "/usr/lib/gstreamer-1.0/libgstamba.so", "/usr/lib/gstreamer-1.0/libgstnnstreamer.so"
The gstreamer daemon (gstd and gst-client) at board's location: "/usr/local/bin/gstd", "/usr/local/bin/gst-client"

  // at gst-client
  12.5.1) pipeline_create p1 amba_venccap name=venc enc=stream_id:0,stop:1,b:0,type:h265,resolution:0.0.1920.1080,start:1 ! amba_vencdemux name=dm dm.stream0 ! queue max-size-time=0 ! h265parse ! mp4mux ! filesink location=/tmp/h265.mp4
  12.5.2) pipeline_play p1
  // change bitrate
  12.5.3) element_set p1 venc enc stream_id:0,bitrate:1000000
  // change absolute bitrate
  12.5.4) element_set p1 venc enc stream_id:0,stop:1,abs-br:1,bitrate:1000000,start:1
  // change vbr range
  12.5.5) element_set p1 venc enc stream_id:0,vbr_bitrate:10000~1000000
  // change bitrate control: cbr, vbr, cbr-quality, vbr-quality
  12.5.6) element_set p1 venc enc stream_id:0,bc:cbr,bitrate:1000000
  // force IDR
