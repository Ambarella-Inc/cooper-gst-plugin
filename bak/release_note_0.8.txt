Ambarella gst plugin and modified nnstreamer plugin release note

Version 0.1 (2022-06-17): basic multimedia elements are added, record scenario are ready, RTSP streaming is not tested (need gst rtsp server), decode scenario have some issues. (see 7. Known issues)
 element list:
  amba_camsrc: Amba Camera Source, output YUV frames
  amba_heicfilesink: Ambarella HEIC File Sink
  amba_hwvdec: amba hw video decoder
  amba_hwvdecsrc: Amba HW decode Source, output YUV frames
  amba_venccap: Amba Video Encoder, capture
  amba_vencdemux: Amba Video Encoder, demux
  amba_vsink: Amba Video Sink
  malsasrc: Audio source (ALSA)

1) Compile the plugin:
 1.1) extract the package (tar jxvf ambarella_gst_2022_06_17_v0.1.tar.bz2), copy it to $(SDK)/ambarella/, the plugin soure code path: $(SDK)/ambarella/mw/amba_gst_plugins/
 1.2) cd $(SDK)/ambarella/boards/cv22_walnut
 1.3) source ../../build/env/aarch64-linaro-gcc.env
 1.4) make sync_build_mkcfg
 1.5) make cv22_ipcam_config
 1.6) make defconfig_public_linux
 1.7) select ambarella gstreamer plugin in menuconfig
    make menuconfig ->
      [*] Build Ambarella Middleware Related  --->
        [*]   Build Ambarella GStreamer Plugin
 1.8) make -j16
Above will compile whole SDK, with ambarella gst plugin. if user only want to compile the plugin, can type
 1.9) make libgstamba.so

The compiled plugin can be found at "$(SDK)/ambarella/out/cv22_walnut/mw/amba_gst_plugins/src/libgstamba.so" or "$(SDK)/ambarella/out/cv22_walnut/fakeroot/usr/lib/gstreamer-1.0/libgstamba.so"

The plugin at board's location: "/usr/lib/gstreamer-1.0/libgstamba.so"

 3.5) gst-launch-1.0 -v -e malsasrc ! queue ! opusenc ! tee name=t t.src_0 ! mp4mux name=mux0 ! filesink location=h265_opus_0.mp4 -e amba_venccap ! amba_vencdemux heic-mode=1 heic-period=10 heic-dump-local=1 filename-base=amba%06d.heic name=d d.stream0 ! queue ! h265parse ! mux0. t.src_1 ! mp4mux name=mux1 ! filesink location=h265_opus_1.mp4 d.stream1 ! queue ! h265parse ! mux1. t.src_2 ! mp4mux name=mux2 ! filesink location=h265_opus_2.mp4 d.stream2 ! queue ! h265parse ! mux2. t.src_3 ! mp4mux name=mux3 ! filesink location=h265_opus_3.mp4 d.stream3 ! queue ! h265parse ! mux3. t.src_4 ! mp4mux name=mux4 ! filesink location=h265_opus_4.mp4 d.stream4 ! queue ! h264parse ! mux4. t.src_5 ! mp4mux name=mux5 ! filesink location=h265_opus_5.mp4 d.stream5 ! queue ! h264parse ! mux5.

 // stop six streams encoding
 3.6) test_encode -A -s -B -s -C -s -D -s -E -s -S 5 -s
